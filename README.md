# 🧪 Prácticas de Automatización con Selenium + Python

Este repositorio contiene ejercicios prácticos realizados durante mi aprendizaje de **automatización de pruebas de software con Selenium y Python**.

Los ejercicios están enfocados en la interacción con elementos de aplicaciones web y en la automatización de diferentes escenarios de prueba.

## 🚀 Tecnologías

* Python
* Selenium WebDriver
* Automatización de pruebas web

## 📚 Ejercicios realizados

### 🔎 `busqueda_google.py`

Ejercicio de automatización de una búsqueda en Google utilizando Selenium.

**Conceptos practicados:**

* Apertura y navegación del navegador
* Localización de elementos
* Ingreso de información
* Ejecución de acciones sobre la página

### 🛒 `ingresar_productos.py`

Ejercicio enfocado en la interacción con productos dentro de una aplicación web.

**Conceptos practicados:**

* Localización de elementos
* Interacción con elementos web
* Automatización de acciones del usuario

### ❌ `intentos_fallidos.py`

Ejercicio orientado a la validación de escenarios de intentos fallidos.

**Conceptos practicados:**

* Automatización de escenarios negativos
* Validación de resultados
* Manejo de diferentes comportamientos de la aplicación

### 🔐 `login_password.py`

Ejercicio de automatización de un proceso de inicio de sesión utilizando usuario y contraseña.

**Conceptos practicados:**

* Localización de campos
* Ingreso de credenciales de prueba
* Interacción con botones
* Validación del flujo de login
